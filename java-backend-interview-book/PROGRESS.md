## If you extend or edit the book

1. Edit only `chapters/*.md`, `extras/*.md` and `question-plan.md`.
2. Question titles in a chapter must match `question-plan.md` verbatim; the validator compares them.
3. The chapter filename → title → question-count table is hard-coded in `scripts/validate.py`;
   update it there if the structure ever changes.
4. Rebuild with the one-liner in `README.md`, and do not commit a PDF that `verify_pdf.py` rejects.
5. `--allow-partial` exists for work in progress: it relaxes the "all 200 written" checks so the
   validator is still useful mid-chapter.

## Environment notes

- The PDF toolchain is Python + reportlab (+ pypdf for verification). Pandoc, LaTeX,
  wkhtmltopdf, WeasyPrint and poppler were not available in the build environment.
- Create the virtualenv as `.venv` in the repository root; it is gitignored.
